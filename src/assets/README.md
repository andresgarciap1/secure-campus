# Recursos visuales

Coloca aquí imágenes que se importen desde un componente React. Por ejemplo:

```jsx
import campusImage from '../assets/campus.jpg';
// Dentro del componente:
<img src={campusImage} alt="Vista del campus" />
```

El proyecto actual usa iconos de `react-icons/fi` y formas CSS, por lo que no necesita imágenes externas. El favicon está en `public/shield.svg`.
